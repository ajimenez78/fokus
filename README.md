# Fokus

**Fokus** is a minimalist terminal assistant built in Python to help you regain focus and reduce distractions through daily intentional routines.

## ✨ Features (WIP)

- Start each day with your 1–3 key intentions
- Choose a focus mode (Pomodoro, Sprints, or Deep Blocks)
- Track your distractions and reflect on your progress
- Simple, offline-first, and distraction-free

## 🚀 Getting Started

```bash
git clone https://github.com/yourusername/fokus.git
cd fokus
python fokus.py
```

## 🧠 Philosophy

> "We suffer more in imagination than in reality."

Fokus encourages clarity, presence, and consistency through lightweight structure—not rigid discipline.
